# Stock Blender addon (future milestone)

GuidedQuad's C++ core is independent from Blender. The adapter will be packaged as a Blender Extension and call the core as a platform-specific executable or shared library. It will support standard Blender Face Sets and Color Attributes before optional Sculpt Extended high-resolution attributes.

No Blender addon user interface is implemented in V0.1. Do not advertise this source folder as an installable addon yet.
