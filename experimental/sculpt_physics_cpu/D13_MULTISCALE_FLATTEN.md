# D13 Multiscale Flatten — first native preview

The D12 planar height chart is reused intentionally as a flatten tool, not as the new Smooth algorithm. Classic remains untouched.
Select NVIDIA Warp Smooth > Very Strong Multiscale and set BLENDER_SCULPT_D13_FLATTEN to adaptive, hard, scrape, or fill before starting Blender (or use GPU smooth mode=flatten directly). Adaptive blends the existing D12 filtered delta with 65% fitted-plane correction; Hard converges to the fitted plane; Scrape and Fill only move in the permitted direction. BLENDER_SCULPT_D13_FLATTEN_MIX (0..1) adjusts the adaptive blend; BLENDER_SCULPT_D13_FLATTEN_OFFSET (-.25.. .25) adjusts the target plane relative to brush radius. No separate brush asset/UI yet.
The fitted plane is recalculated per dab; no persistent plane, adjustable grid resolution, actual volume removal, or dedicated Warp flatten kernel yet. Existing D12 GPU filter may run; the new blending/projection runs on CPU. The normal native contact guard and clipping still apply, so final motion can be reduced. Unsupported charts are rejected without substituting a different tool on supported Mesh dispatch. Test ordinary Mesh, symmetry off, Preserve Shape off; Multires/Dyntopo are not implemented. 
The standalone fixture checks signs, mask/weight, offset and bounds. Not compiled or runtime-tested here. Next: persistent stroke plane, robust fitting, edge profile, scale and curvature controls, separate native asset/UI and GPU fusion after numerical parity.
