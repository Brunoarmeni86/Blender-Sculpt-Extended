# D14 V2: additive Clay and continuous material transition

Opt-in BLENDER_SCULPT_D14_CONTINUOUS_FUSION=1 replaces the positive D12 Clay-family deposit and prior fusion stage. ClayBulb round, Clay round, ClayStrips mixed square/round tool profiles remain distinct. Additive dose integration removes the moving plane target and uniform .24/.30R stroke-wide saturation. Ordinary dabs sum with arc length; a smaller first-touch dose .03 avoids stamping at a stroke start; stationary input and discontinuous jumps do not deposit. The .16R single-dab safety cap, existing contact/triangle guards, and native Undo remain. No absolute stroke-height cap in this experiment: prolonged repeated deposition can create excessive growth; evaluate carefully. It does not guarantee spacing invariance when the live geometry, pressure, normals, texture, host envelope or safety limit changes. Round profile clipped quadrature; mixed square profile approximate midpoint integration. Raw support .94R leaves a small collar inside the native footprint. Native PBVH gathering extends before Undo; no writes outside native permitted envelope. Existing contact may taper geodesic reach and depth if enabled. Inverted deposition uses previous solver; host swept selection may still differ under the opt-in.

V2 exchange allows zero-raw-deposit writable receivers/donors in an intrinsically connected collar. Soft activity propagation, oriented edges, local relief and excess displacement gradient drive three conservative net-budget exchanges; old relief is not labelled material provenance. No generic Smooth. The V1 weighted median itself is not used in V2 (gradient/relief exchange supersedes it); the conservative interface principle remains. Exact enclosed volume, post-write conservation, collision-free deformation, global continuity, and production performance are unverified. CPU constructs graph, existing Warp exchange optionally executes each pass; strict balance can fall back to CPU. Diagnostic [D14 Continuous Fusion] reports proposals; [D14 Continuous write] reports actual area-weighted axial displacement after native write on logged dabs. BLENDER_SCULPT_D14_FUSION_DIAG=1 logs all dabs. Compare with V1 by unsetting V2 flag. Test includes additive accumulation beyond old cap, partitioned round dose, zero-deposit collar, mask, disconnected vertex, old-material mobilisation, conservation and zero dose. No compile/runtime claim at publication.
