# D14 ClayBulb independent reference

Opt-in BLENDER_SCULPT_D14_CLAYBULB=1 only for physical dedicated Clay family assets whose ID name contains ClayBulb (case/space-insensitive). Optional BLENDER_SCULPT_D14_CLAYBULB_NAME selects exact actual ID display name. Other Clay/Clay Strips retain D12/D13 behavior. Logs identify asset and path. No new DNA/RNA or asset migration.

The moving plane target is replaced by a convex compact C2 additive radial deposition profile, integrated along the actual previous-to-current cursor segment using clipped four-point quadrature. Zero movement after first dab deposits nothing; jumps over 1.5R do not deposit along the gap. Stable D12 frame supplies orientation, not a plane target. Smooth saturation against stroke-local reference caps displacement at .30R. Gain .27 is initial calibration (strength 3 first-dab target approximately .045R at full envelope). Native factors remain authoritative; round swept candidate PBVH gathering occurs before Undo in both Clay and Clay Strips host adapters. Pressure/alpha use host current dab envelope, not historical interpolation; geometric integral exact only at constant depth and fixed position. Existing D13 thin contact remains optional; not exact thickness or CCD.

For positive bulb deposition an independent pair exchange uses live ridge residual measured against averaged local normals, actual lumped areas, donor budget of newly deposited volume proxy, and receiver headroom. It can adapt new deposition to previous stroke relief but does not remove existing material or guarantee exact volume after guard. Reuses CPU/Warp paired exchange if available. One-ring transport remains resolution-dependent; no claim of full volumetric clay fusion or GPU-resident bulb kernel. C++ test added for profile, mask/backface, cap, partitioned quadrature, and conservative fusion. Native build and runtime unverified at publication; evaluate on ordinary Mesh, symmetry off. Logs [D14 ClayBulb CPU] and [D14 ClayBulb fusion]. If [D12 Clay CPU] remains, inspect new asset= field and set exact name override. Disable flag for old behavior.

Hot-path review: asset name matching, sweep detection and normal normalization are performed outside per-vertex gathering, avoiding repeated environment lookups and string allocations on dense sculpt meshes.
