### Integration stages
1. Gather native factors BEFORE native displacement/zero-goal filtering. Exact pressure/falloff/alpha/automask semantics; do not multiply pressure twice. Resample by arc length in brush-radius units, separately support time-based airbrush dwell. Distinguish no gesture from saturated native target. Integrate on compact local island and retain native Undo/writeback. Initial Clay, Clay Strips, Draw, Inflate, Flatten/Scrape/Fill, Smooth/Relax, Nudge; each needs an action-specific numerical contract. Smooth radius must be independent of local tessellation.
2. Persistent sparse material state: plastic strain/rest configuration, compaction, viscosity, yield and recovery. Stage and acknowledge state only after editor write; native Undo/Redo, cancellation, external edit invalidation, save/load policy and mesh/layer identity must be designed first. Do not store mutable state inside shared immutable topology cache. Distinguish stroke-local from cross-stroke persistence.
3. Extend Grab, Snake Hook, Thumb, Elastic Deform, Pose, Pinch, Crease, Layer, Cloth and remaining deform brushes with suitable action policies; avoid forcing pose/cloth or elastic grab into a clay compression law. Paint/Mask/Face Sets use attribute-specific actions, not automatic vertex deformation. Dyntopo/Remesh/Tear require topology and UV migration transaction.
4. Area/volume constraint based on faces, not edge-length proxy; open surfaces require a defined local thickness or reference volume, not a global closed-volume assumption. Benchmark elastic/plastic response, mesh density, overlap and long strokes.
5. Actual symmetry aggregation, Multires/Sculpt Layers and CPU parallel/CUDA parity, including devices without NVIDIA. Benchmark end-to-end p50/p95, cold/warm topology, memory, and no hidden fallback.

Acceptance gates: zero pressure/mask produces no effect; 10 repeated passes remain responsive with identical gesture even where native plane saturates; same sampled path at different event rates and mesh densities gives comparable shape; no NaN/pinned writes; exact UV/attribute/topology checks and Undo/Redo; measurable shape metrics and artist feedback. #### True Grab Tear on Multires — requirement and reconstruction paths
Not limited to an apparent tear. Tier 1: live breakable proxy bonds and preview, no native topology change during the dab. Tier 2: deferred explicit topological tear after stroke, first support cuts aligned to coarse mesh edges: preserve face/corner identity, duplicate seam vertices, split incident face fans and update connectivity; snapshot evaluated surfaces and every sculpt layer, rebuild subdivision evaluator, re-encode displacement in the new tangent frames. The existing branch has multiresModifier_reshapeFromCCG and multires reshape helpers; their presence does not establish support for changed topology. Tier 3: arbitrary fine-level tear crossing coarse faces: locally retopologize/reparameterize, transfer UV per corner, reconstruct base and layer displacements via provenance-aware sampling of old patches, handle new crack walls with explicit new attributes. Exact preservation of all levels/details is not generally possible after arbitrary cuts. Explicit destructive alternative: duplicate object, realize evaluated high-resolution mesh, cut and optionally reconstruct a new Multires hierarchy. Keep original until validation succeeds. Treat as heavy transactional operation with rollback, memory/time budget, Undo and topology/UV/layer checks; no live topology edits on existing compact solver indices. None of these tear paths implemented yet.
