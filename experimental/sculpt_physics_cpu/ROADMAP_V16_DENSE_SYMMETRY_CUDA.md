### Integration stages
1. Gather native factors BEFORE native displacement/zero-goal filtering. Exact pressure/falloff/alpha/automask semantics; do not multiply pressure twice. Resample by arc length in brush-radius units, separately support time-based airbrush dwell. Distinguish no gesture from saturated native target. Integrate on compact local island and retain native Undo/writeback. Initial Clay, Clay Strips, Draw, Inflate, Flatten/Scrape/Fill, Smooth/Relax, Nudge; each needs an action-specific numerical contract. Smooth radius must be independent of local tessellation.

Stage and acknowledge state only after editor write; native Undo/Redo, cancellation, external edit invalidation, save/load policy and mesh/layer identity must be designed first. 3. Extend Grab, Snake Hook, Thumb, Elastic Deform, Pose, Pinch, Crease, Layer, Cloth and remaining deform brushes with suitable action policies; avoid forcing pose/cloth or elastic grab into a clay compression law. Paint/Mask/Face Sets use attribute-specific actions, not automatic vertex deformation. Dyntopo/Remesh/Tear require topology and UV migration transaction.
4. Area/volume constraint based on faces, not edge-length proxy; open surfaces require a defined local thickness or reference volume, not a global closed-volume assumption. Benchmark elastic/plastic response, mesh density, overlap and long strokes.
5. Actual symmetry aggregation, Multires/Sculpt Layers and CPU parallel/CUDA parity, including devices without NVIDIA. Benchmark end-to-end p50/p95, cold/warm topology, memory, and no hidden fallback.

Melt diffuses residual relief against a weighted quadratic chart, maintaining exact quadratic equilibrium in ideal data; this is not true thermal rheology or exact sphere preservation. Singular fits suppress diffusion. Deposit has no behavior change. Added equilibrium, relief diffusion and sparse support tests. No native compile or test run here. Swept PBVH, actual persistent material field, collisions and GPU remain pending.

### V28-B2 assisted Clay XPBD

It preserves pinned vertices and native targets before XPBD; does not guarantee long-term strain or self-collision safety. No extra relaxation of absolute geometry. With OPTIMIZE_V27C also enabled, contiguous local island IDs are validated and indexed directly rather than searched during target staging/blending. Added exact dense lookup parity and guarded-edge tests for both Clay tools; no runtime execution here. CPU/GPU parallel constraint solve remains pending.

### V29-A swept candidate dispatch and native CPU parallel constraints

Native build only: BLENDER_SCULPT_XPBD_V16_COLORED=1 uses existing deterministic color order with parallel bond processing at >=2048 bonds via Blender threading; barrier between each color, fixed-fixed skip, abort isolated solve on worker failure. Standalone reference retains serial colors. No native build or measured speedup here. No global collision guarantee or persistent across-stroke material field, GPU not integrated.

### V29-B persistent compaction attribute (experimental native integration)
BLENDER_SCULPT_PLASTIC_V29=1 with STABLE_V28 enables qualitative compaction hardening for Press/Compact/Compress only on normal Mesh with an existing float POINT attribute named .bse_plastic_compaction. Initialize in Object Mode (Python console): obj=bpy.context.object; obj.data.attributes.new(name=".bse_plastic_compaction",type="FLOAT",domain="POINT") if obj.data.attributes.get(".bse_plastic_compaction") is None else None. Save the blend. The attribute persists across strokes and files. Read prior field while planning; harden inward motion (then rebalance the volume ratio); update only actual staged native translations after geometry writes; inverse compression loosens the field. Sparse first-write values captured in native Position Undo step and exchanged on ordinary mesh restore; topology/attribute absence guards. This is scalar qualitative hardening, not full tensor plasticity, mass, density or constitutive MPM state. No attribute creation mid-stroke. Other tools do not modify this state; no transport of compaction, Multires or topology-change validation. No actual native build, Undo/Redo or file save/load tests performed here. Keep disabled until verified on a disposable mesh.

### V29-C global swept AABB guard (opt-in expensive reference)
BLENDER_SCULPT_COLLISION_V29=1 rebuilds a global triangle AABB index for every physical dab after local contact limiting, before native write staging. For nonadjacent triangle pairs whose initial AABBs are separated, a common conservative scale keeps their swept AABBs separated over the linear displacement; cap candidate pairs and fail closed for budget exhaustion. Existing overlapping initial boxes are counted as unresolved, adjacent pairs skipped: this is NOT exact continuous triangle collision detection and cannot guarantee global absence of intersections. False positives possible; high-density cost unmeasured. Added crossing and separating tests, not executed. Native clipping/writeback still requires normal validation. Next: reusable BVH/refit and exact triangle CCD for unresolved pairs.

### V30-A live current-surface accumulation (opt-in corrective checkpoint)
BLENDER_SCULPT_LIVE_SURFACE_V30=1 for explicit physical Clay/Clay Strips SPACE/AIRBRUSH on ordinary Mesh forces current-coordinate raycast (including original request during the active physical stroke), current PBVH bounds, dirty-normal refresh before plane sampling, no original normal/plane locks, current rest positions for compact native solve, and fresh relative Press/Scrape plane per dab. No first-contact coordinate cap or absolute projected slope ceiling in the live solver; use bounded incremental relative motion on current 3D edges plus existing per-substep travel, paired flux, signed volume and native triangle checks. Geometry accepted at one dab is the next dab's base; Undo remains separate. Scalar compaction persists if V29 plastic field is enabled. Does not allow remapping steep back-facing/folded charts; local contact and existing chart/connected component checks can still reject some vertices. No exact CCD guarantee or runtime speed/quality validation; keep global AABB guard off for initial comparison. Added stale-history vs fresh-input and repeated Scrape test; not executed here.
