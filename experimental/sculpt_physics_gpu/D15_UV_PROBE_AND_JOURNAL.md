# D15-C4 — native UV dry run and sparse journal reference

Native read-only opt-in probe in smooth.cc. Set BLENDER_SCULPT_D15_FEATURE_SMOOTH=1 and BLENDER_SCULPT_D15_UV_PROBE=1 before launching, disable all symmetry, use ordinary mesh and UV maps. No position or UV writes in this diagnostic path. Default and B1/B2 feature mode unchanged with probe flag absent. It stages tangential-only interior motion, excludes all feature vertices, applies native clipping and local triangle guard, and samples the original incident triangle fan. Uses actual mesh corner IDs and all UV layers; requires a connected fan, valid oriented triangles, one continuous destination wedge, and bounded projection residual. All layers share a single geometric barycentric hit, near ties with different sampled UVs refused. Logs [D15 UV Probe READ ONLY], layer/projected/refused counts and hypothetical corner values / maximum UV delta. Caps 4096 moved vertices, 16 maps, 256 triangles/corners per fan. This is diagnostic only: no retained batch, no native attribute write, no actual texture modification. No UV wedge split sliding, global chart construction or full D15-C2 bounded adjacency walk; uses conservative local fan instead. The caller must not interpret a successful log as validated texture preservation. Untested native build/runtime. No UI or PTX changes.

Independent Journal reference stores first old float2 value by layer name and corner index, with caller-defined object/topology identity. Repeated dabs do not replace original value. Complete key set and finite values validated before Undo/Redo exchange. Failure leaves journal/live values unchanged. Temporary map copy on capture is reference-only, not optimized. Identity tokens are supplied by caller: name alone cannot distinguish deletion/recreation, and native topology_matches currently checks only vertex count for ordinary Mesh. Need real topology/layer identity or strict scope/lifecycle validation before native integration. No hook in StepData yet and no claim native Undo works. Native sidecar must preflight before position restore, account memory, validate active step/cancel paths, acquire all writers before mutation and avoid split geometry/UV failure. See C3 audit. Do not enable actual UV writes before native tests.
