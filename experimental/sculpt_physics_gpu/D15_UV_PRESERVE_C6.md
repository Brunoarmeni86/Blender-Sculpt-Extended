# D15-C6 — experimental BSE Preservation Engine: tangent UV preservation

After the user-reported successful cumulative C5 native build and C4 probe log (one UV layer, 326–364 projected vertices/dab, zero refusals; tiny UV deltas), introduce actual UV publication only under explicit environment opt-in. The C5 log does not validate native UV Undo; the sidecar was dormant.

## Modes (restart Blender between tests)
- Existing default: no D15 feature flag, native/existing Smooth variants unchanged.
- BLENDER_SCULPT_D15_FEATURE_SMOOTH=1 and BLENDER_SCULPT_D15_TANGENT_ONLY=1: tangent-only control, no UV writes, pin all features.
- FEATURE_SMOOTH=1 and BLENDER_SCULPT_D15_UV_PROBE=1: old read-only diagnostic, takes precedence over preserve.
- FEATURE_SMOOTH=1 and BLENDER_SCULPT_D15_UV_PRESERVE=1: tangent-only position plus UV changes, C5 sparse native Position Undo capture. Logs [D15 UV STAGE] and [D15 UV Preserve COMMIT]. Still hidden, not an ordinary brush option. No change to native Grab/Pose/Clay, topology, PolyPaint, mask or Face Sets. C6 all existing UV maps or none; per-layer UI selection later.

## Scope
Ordinary mesh, symmetry off, no deform modifiers/shape keys/Multires. One continuous wedge per moved vertex across every map. All feature vertices pinned. Retain mask, native clipping and local contact guard. The C4 incident fan produces shared source barycentrics and all-layer corner proposals. Refused correspondence rejects the entire dab (rather than changing geometry with missing UVs). Caps from C4 plus 262144 proposed changed corner values. Validate native Position Undo node coverage and acquire all affected attribute writers before capture; check staged UV triangle orientation and at least 5% of original signed area magnitude for affected existing triangulation (reject degenerate input or inversion); use float32 target UVs. Then capture first old/last expected UVs with C5, apply native positions, write staged UVs, finish writers and dirty all leaf attribute batches. No fallback after publication. This is a conservative preflight, NOT a proven exception-atomic transaction: native writes/finish/tag and undo-stack/cancel semantics still require testing. Full connectivity scan and sparse journal copy per dab, whole-layer writer acquisition and all-leaf dirty tagging may be expensive. Not real-time validated; do not enable on production assets. Triangle guard is local to current triangulation and does not guarantee no distant UV overlaps or no stretch. No support for seam sliding, new topology, disconnected wedge transport, arbitrary deformations or selective individual channels yet.

## Validation
Connector source inspection and publication only for C6; Windows build and runtime not run here. Use disposable duplicate of irregular planar grid, checker texture, two UV maps, all symmetry off. Compare tangent-only A vs preserve B on identical mesh and stroke, with actual displacement sufficient to show visible texture change. Save original and resulting positions plus UV coordinates; compare exact Undo/Redo and Esc, multi-dab, repeated strokes, mask, pinned seams and refusal. Check no change with probe. Record COMMIT counts and native errors, frame time and UV delta; if zero commits or negligible motion do not infer success. Repeat on curved mesh and near seams before dense benchmark. If unexpected behavior, remove preservation env flags and restart. Do not advertise validated feature or extend to other brushes until C6 passes. User design decision: selective optional BSE Preservation Engine with separate Attribute Transport, Surface Anchoring, Detail Preservation and Topology Transfer; separate material advection from tangent reprojection and topology transfer.
