# D15-C9.2 watched vertices

User supplied 360 selected vertex IDs in the problematic region (2368..3927, noncontiguous). Selection is a region, not proof that all 360 are immobile. C9.2 is diagnostic only. With BLENDER_SCULPT_D15_COVERAGE_DIAG=1 and BLENDER_SCULPT_D15_COVERAGE_IDS set to a comma-separated list of those exact IDs, C9.1 now emits [D15 C9.2 Watch] for every watched ID per observed GPU dab, including outside-radius vertices, and [D15 C9.2 Factor] for watched vertices encountered in the native Smooth factor pipeline (per-node, before brush-strength multiplier). Labels distinguish empty gather, GPU no-deformation before fallback, and published. Native factor stage logs may also be emitted by native Smooth; GPU Watch only when A3 adapter invoked. Observe numeric fields rather than treating exclusive reason as a proof of root cause. Full-mesh watch limit inherited 250000 verts; unsupported paths, all-empty upstream node mask, exceptions or disabled GPU produce no Watch report. The watch list parser accepts nonnegative comma-delimited integers only, up to 4096 entries; malformed list disables watch. Vertex indices must remain unchanged, use same saved mesh without remesh/Dyntopo/vertex reorder. Log may be verbose; use one short stroke centered on residual crest. No UV, geometry, masks, solver, selection or Undo changes. Native compile/runtime not tested here.
