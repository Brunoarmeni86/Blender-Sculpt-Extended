# D15-C6.1 — local rejection recovery and diagnostics

User reports Smooth does not work in C6 mode B. No C6 diagnostic log yet, so root cause is not confirmed. Source audit found all-or-nothing rejection: one unsuitable source fan, non-tangential clipped translation, ambiguous UV or folded UV triangle could freeze the entire dab. C6.1 removes unsafe vertex proposals, restarts from the remaining guarded motion, re-runs local geometry guard and reprojects every retained vertex/all layers from unchanged source. For invalid UV triangles remove moving endpoints; discard prepared writers before retry; up to six rounds, no unsafe geometry-only fallback. Native clipping changes are pinned in tangent-only modes; no partial snap. Capture remains last after writer and geometry checks. No change to other Smooth modes.

Diagnostics: [D15 UV Reject] classifies normal, fan, residual and UV correspondence refusals; [D15 UV Preserve FILTER] reports removals; [D15 UV Preserve BLOCK] distinguishes scope, zero eligible motion, projection, writer, no safe subset, missing position node, UV undo capture. [D15 UV Undo BLOCK] identifies active step/stale values. COMMIT remains success marker. Still no support for symmetry, grids, Dyntopo, mesh without UV, >4096 moved vertices, >16 maps; pure tangent redistribution can be nearly invisible on regular topology. Area guard remains conservative; repeated pinning may reject all. Retry cost may be high; no performance claim. Full native compile/Undo/Redo/runtime not executed here. Use disposable mesh. Do not remove protections just to make Smooth move. If blocked, collect the first STAGE/Reject/FILTER/BLOCK lines; if COMMIT appears but motion is tiny compare with tangent-only A on irregular plane.
