# D15-C7.1 — local Smooth coverage, normal material transport

User reported small regions missed by C7 Smooth. Prior C6.2 successful log contained repeated residual refusals and transient UV split detections; C7-specific failure log absent. Source audit confirms two coverage losses: all UV-only feature vertices were pinned, and rejection of tangent reprojection removed the entire motion, including normal smoothing. This change targets those paths rather than weakening mask/visibility, native clipping, topology or geometry safety. 

C7 only: UV seam/chart tags no longer act as geometric-feature flags for the solver; affected vertices are constrained to normal-only material motion, preserving both original UV wedges. Mixed sharp/open/Face Set/guide boundaries remain pinned, and invalid/hidden/nonmanifold edges remain blocked. When local UV correspondence or UV triangle area guard rejects a candidate, try its original clipped normal component once, reapply clipping/locks, and re-run all guards before capture/publication. No new motion, no geometry-only fallback of tangential motion. If normal component is zero or unsafe, remove vertex as before. UV triangle rejection now identifies only changed UV endpoints. Pure-normal tolerance 1e-6 relative to total motion accounts for float32 rounding; no world-space tolerance. Native geometry guard and Undo pipeline retained. C6 tangent Relax and unrelated brushes unchanged except conservative UV guard endpoint refinement. C7 A/B uses the same seam normal policy; B may recover/prune additional vertices. No guarantee that all regions will move: masks, real feature constraints, no normal component, contact guard, clipping, unsupported topology and retry cap still apply. New [D15 C7.1 Coverage] active, moved (candidate entries), seam_normal, normal_recovered (attempts), uv_removed (pruned), geometry_pinned, blocked, clip_pinned. Native C7.1 compile/runtime not executed here. Added standalone normal-component tests, native validation still required; no assertion of Undo/Redo correctness. Compare same mesh A and B, repeat near seam and feature junction; check UV corner values, visual texture, geometry, Undo/Redo and Esc.
