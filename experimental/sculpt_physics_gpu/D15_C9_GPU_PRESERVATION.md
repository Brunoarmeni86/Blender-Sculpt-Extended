# D15-C9 — Very Strong GPU + independent UV preservation pilot

User C8 visual A/B after Clay Strips showed remaining crests, steps and small residual patches. C8 has one weighted Laplacian pass and may prune vertices; do not make that CPU pilot the default. Keep the existing recovered Classic Very Strong A3 solver and its own native masks/falloff/clipping/Preserve Shape, no change to GPU kernels or strength. New opt-in BLENDER_SCULPT_D15_GPU_PRESERVE=1 with GPU_SMOOTH_A1=1, GPU_SMOOTH_MODE=strong, D13_SMOOTH_RECOVERY=classic. Clear FEATURE_SMOOTH (it dispatches first). C9 stages exact A3 position displacements before writes and projects only tangential component using existing C8 connected per-map wedge logic. Does not prune positions or weaken them due to UV rejection. Explicit local material transport keeps original UVs of rejected vertices. UV area guard removes only corner proposals from rejected endpoints, revalidates remaining proposals for up to six rounds; global UV preflight, writer or Undo refusal leaves all UVs unchanged for this dab and records reason. This is a geometry-first policy, not a guarantee of preserved visual texture for rejected areas. No new geometric guard: inherits legacy A3 geometry safety and native clipping. Native Undo sidecar capture only in C5 supported scope; no symmetry, modifiers, shape keys, Multires, active layer or Dyntopo for UV writes. Unsupported UV scope uses material transport with diagnostic. C8 remains available separately. C9 only dedicated DenseStrong A3, not multiscale/flatten/other brushes. Geometry sync back to resident solver after native accepted writes unchanged. Failure after publication begins cannot cause second smoothing. Native transaction not exception-atomic; rare publish failure remains unresolved. Native compile/runtime/Undo not tested here. A/B using exact same initial mesh, fixed strokes (same strength/radius, Preserve Shape off) C9 flag off/on. Compare positions, residual crests, UV checker and native Undo/Redo/Esc; log [GPU Smooth A3 CUDA], [D13 Smooth sync], [D15 C9 GPU Preserve]. Counts are per dab, not unique over stroke; material_vertices includes local UV rejection or global fallback; pure normal motion with unchanged UVs is intentional and not counted as rejected. No persistent stroke anchors, valence solver, general brush integration or GPU UV transport yet. Cap inherited 4096 moved vertices and 16 UV maps; larger dabs explicitly keep UVs. Geometry/UV staging remains CPU and can be costly.
