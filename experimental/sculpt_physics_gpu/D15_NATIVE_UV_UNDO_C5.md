# D15-C5 — native Position Undo UV sidecar (dormant)

Native scaffolding in sculpt_undo.cc/.hh and sculpt.cc, separate from experimental brush engine. No capture caller exists yet; UV Probe remains read-only. No UI, asset or CUDA change. The normal Position step owns an optional sparse payload keyed by native UV layer name and corner index; first old and last expected live values recorded across dabs. The caller must pass an already validated complete set of proposed float2 corner values immediately before a no-fail combined geometry/UV publication. Do NOT call capture without publishing the exact proposals; the API currently has no cancellation token for a failed publication. A normal stroke never allocates the sidecar. CPU reference Journal C4 remains separate and tested previously; C5 native specialization is not the same code and is NOT runtime tested.

Native capture checks active Position step, node capture, object name, ordinary Mesh, no active shape/deform/Multires layer, vertex/corner counts, finite values, UV metadata, exact expected live values and topology fingerprint. Whole connectivity fingerprint includes edge endpoints, face offsets and corner vertices/edges; stronger than vertex count, but a 64-bit hash is not a collision-proof identity and layer name/value equality cannot detect identical layer recreation. Full scan and map copy are reference costs; memory estimate includes map entries and names, not an allocator measurement. Before stack restore, verify live state, reacquire all layer writers before exchanging positions, then swap original/expected UVs, finish writers and invalidate PBVH attribute caches. Esc/anchored stroke replay restores original values without swapping; this is the separate restore_position_from_undo_step path. Native decode wrappers avoid flipping their local is_applied flag or continuing the same-type loop when UV restore was refused.

Critical limitations: Blender global Undo stack decode has void callbacks; stopping a native loop is not proof the global undo cursor rolls back. Restore_list can run metadata work before position exchange. Need verify rejection behavior, all writer acquisition/lifetime, exception and cancellation ordering, memfile boundaries and actual position/UV atomicity before allowing a capture caller. Cancel helper currently writes UVs before native position restoration, not an all-or-nothing transaction if later native restoration fails. It is not safe to activate yet. Also need bound capture cost, destination coverage by Position Undo nodes, native dirty notifications beyond PBVH if required, identity on layer rename/recreate and attribute schema changes. Native tests: ordinary Mesh multi-dab, two UV maps, repeat original capture, exact undo/redo across steps and memfile boundary, Esc/anchored replay, rejection of stale topology with same counts, stale layer value/metadata, mask/hidden, no regression with no sidecar. Ensure original UV Probe still produces no geometry/attribute write.

Validation: source audit and connector publication only; C5 not compiled or run in Windows/Blender. No new standalone tests claim. Keep UV writes disabled; next step review native build plus add a guarded publisher that stages proposals, acquires writers, preflights Undo and supports rollback, then test on disposable mesh. Do not treat this as user-ready UV-preserving Smooth. Existing C4 journal regression results do not validate native hooks.
