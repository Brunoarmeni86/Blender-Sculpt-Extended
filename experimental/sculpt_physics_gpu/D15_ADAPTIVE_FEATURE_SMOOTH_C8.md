# D15-C8 — optional adaptive feature and connected UV wedge pilot

C8 adds a separate opt-in to C7.1, with no change intended to native Smooth dispatch. BLENDER_SCULPT_D15_FEATURE_SMOOTH=1, BLENDER_SCULPT_D15_UV_SCULPT=1, BLENDER_SCULPT_D15_UV_PRESERVE=1, BLENDER_SCULPT_D15_ADAPTIVE=1. Clear ADAPTIVE to compare C7.1. Clear UV_PRESERVE for geometry-only C8 control. Probe off; ordinary mesh only, no symmetry/modifiers/Multires. C8 permits smooth soft-boundary chain tangent and normal motion, soft ends/junctions normal only, hard coherent chains slide and hard junctions stay pinned. Face Set constraint soft by default; BLENDER_SCULPT_D15_PROTECT_FACE_SETS=0 ignores Face Set edge labels in C8, not native automasking. UV charts per layer partition connected triangle fan with matching vertex identities and UVs at BOTH shared edge endpoints. Each corner belongs to exactly one wedge; source candidates, residual and ambiguity checks per wedge. Stage all layers or recover normal only for soft vertices; never recover hard-feature normal motion. Retain area guard, clipping, mask/visibility and C5 Undo. No larger search radius, GPU integration, valence-adaptive solver or exact crease preservation yet. Native source build/runtime/Undo not tested here. New standalone fixtures added but not executed here. Reference: SculptCore bsmooth.sbrush blob 067a606f3cb197189dcdfb36b9eab9d6dacadbc3 and uv_reproject.cc blob 4845e2ddcdd5efde74faec34f2e49f0bee6e6ecd, independent implementation, existing BSE anchor/feature helpers. New logs [D15 C8 Wedges] and [D15 C8 Adaptive], C7.1 Coverage. Wedge group counts are attempted samples, not confirmed unique successful vertices. Projection remains conservative; small inactive patches may remain. Compare C7.1, C8 without UV, C8 with UV on identical test mesh, verify exact Undo/Redo/Esc before broader port.
