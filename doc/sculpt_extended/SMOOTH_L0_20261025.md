# Blender Sculpt Extended 5.2.3 — Smooth L0 and RNA corrections

This revision includes the previous Clear Mask, Face Sets, Undo, compact Multires UI and Polypaint fixes.

- Preserve Other Layers supports Smooth and Shift+Smooth after sculpting a layer at level zero and subdividing. Other layer payloads remain unchanged. Preserve OFF uses native Smooth.
- The numerical L0 reference shares the live Multires topology and is prepared with the CCG, rather than constructing another topology per stroke. One reference slot is retained per live CCG, with invalidation on L0 data/strength changes and explicit cleanup before the borrowed topology is destroyed.
- Compact affected-grid sample buffers and within-stroke grid reuse reduce repeated preparation. Halo samples remain sparse. No brush formula or persistent layer format changes.
- OpenSubdiv explicitly reuses matching existing refinement instead of calling RefineAdaptive twice. Incompatible refinement settings fail without mutating shared topology.
- Five custom operator string defaults now use nullptr as required by RNA_def_string. Their effective defaults remain empty strings. The five startup RNA errors are removed.

## Validation and limits

Windows: seven targeted L0/isolated Smooth checks including Shift, Undo/Redo, Commit, save/reopen and protected layer payloads passed. Two fixed dense-scene replays retained bit-identical final geometry after the OpenSubdiv fix. Five RNA properties retained identical defaults/type/length and accepted both empty and explicit values. RNA startup errors and the OpenSubdiv duplicate-refinement error are absent in targeted checks.

Earlier local buffer A/B measurements improved median stroke time in two cases, but are not universal performance guarantees. GPU hardware and 8 GB laptop behavior have not been tested. L0 isolation requires Multires first in the modifier stack; this revision does not enable Armature-before-Multires isolation or change Pose/Grab behavior.

Linux is published only after its own compile/startup, brush and mask checks, new Smooth L0 and RNA regressions, glibc <=2.28 audit, GPU kernel presence and Ubuntu 24.04 startup checks pass. Packaged CUDA/OptiX, HIP and oneAPI kernels do not imply physical GPU testing.

The scripts in tests/ require this custom Blender revision. smooth_routing_regression.py supplies fixtures to smooth_l0_isolation_regression.py; its standalone historical guard expectations are not a current regression test. Run the isolation script, not the historical routing test, for the current behavior.
